# dsh-think-game · 市场提交文案 / Market submission copy

## 一句话 / One-liner

- **EN**: Inline mini-game arcade beneath DSH streaming reasoning: Breakout, Snake, Reflex, 2048, Memory, Stack and Flappy, with auto-pause/fade and an optional continue entry.
- **ZH**: 嵌在 DSH 流式思考下方的轻量小游戏：打砖块、贪吃蛇、反应力、2048、记忆翻牌、堆塔和飞行，思考结束时自动暂停/淡出，可继续上一局。

## 长描述 / Longer description

- **EN**: A dependency-free DSH client plugin that places a compact, theme-aware arcade directly below the live “thinking / deep diving” module in the conversation flow. It appears automatically while the model works, pauses and fades when the answer starts, supports random rotation or a pinned game, remembers best scores, has optional WebAudio sound, and keeps keyboard input isolated from the composer. Seven small games share one minimal DSH-style panel; an optional “Continue” entry lets the user finish a run after the answer starts. MIT licensed.
- **ZH**: 一个零运行时依赖的 DSH Client 插件，在会话流的「深度求索中 / 思考中」模块正下方嵌入一个紧凑、跟随主题的小游戏面板。模型工作时自动出现，开始回答时暂停并淡出；支持随机轮换或固定一款、最佳成绩、可选 WebAudio 音效，并保证键盘输入不干扰输入框。七款小游戏共用一套简洁的 DSH 风格面板；回答开始后还可以通过「继续上局」玩完刚才那一局。MIT 开源。
